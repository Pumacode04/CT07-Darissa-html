Game Design: Hangman-Inspired Word Puzzle
Role
You are an expert JavaScript developer and game designer. Create a complete, beginner-friendly browser game using p5.js and p5play. Produce working, readable code and follow the requirements below.

Game Details
Genre: Puzzle
Theme: (__________)
Objective: Guess the hidden word before the hangman drawing is complete.
Inspiration: Hangman
Files
Create two new files:

__________.js — contains the complete game logic.
__________.html — loads the required libraries and runs the game.
Update the existing homepage index.html to include a clearly labeled link to the new game. Match the project’s existing style and use the correct relative path.

Gameplay
Choose a word at random from a small, beginner-friendly list that matches the selected theme. Keep the word list easy to edit.
Display the theme in bold at the top of the game.
Show the hidden word as one underscore per letter. Reveal correctly guessed letters in their matching positions.
Let the player choose either Guess letter or Guess word. Each option should let the player enter their guess.
Accept guesses using the mouse and keyboard. Validate and normalize input, such as trimming spaces and ignoring letter case.
A wrong letter guess or incorrect whole-word guess adds exactly one stroke to the hangman drawing. A repeated letter guess must not add another stroke.
Show incorrect letter guesses in a dedicated area, with each letter in bold and a red cross beside it.
Give clear feedback for invalid input, repeated guesses, correct guesses, and incorrect guesses.

Win, Loss, and Restart
The player wins when every letter in the word has been revealed.
The player loses when the hangman drawing is complete.
Clearly display the outcome and prevent further guesses after the game ends.
Provide a way to start a new round, selecting a new random word and resetting all round state.

Controls and Presentation
Use mouse presses on controls labeled exactly Guess letter and Guess word to choose a guess type.
Make the input and submit action obvious and usable with both mouse and keyboard.
Keep the interface readable, with the theme, hidden word, wrong guesses, hangman drawing, and game status easy to distinguish.
Support common desktop and mobile screen sizes without overlapping or clipping content.

Technical Requirements
Check the documentation or source for the specific p5.js and p5play versions you select before using their APIs.
Load compatible, pinned library versions in the HTML file. Use the project’s existing conventions where practical.
Use p5play only where it is useful; do not add unnecessary physics or sprites to a word-guessing game.
Avoid p5play-reserved property names, including physics and shape properties, for custom game data. Use distinct names for custom state.
Keep game state and round logic organized so each guess updates the display and win/loss checks correctly.
Make the game playable from start to finish without requiring a build step or external services.

Verification
Before finishing, check that:

The HTML page loads without console errors.
Both guess modes work, including invalid and repeated guesses.
Correct and incorrect guesses update the word and hangman as specified.
Win, loss, and restart all work.
The homepage link opens the game.
The selected p5.js and p5play APIs match the loaded library versions.
